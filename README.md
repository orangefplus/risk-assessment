# 信贷风险评估代码（Credit Risk Assessment）

本项目实现了一套基于多源数据（企业工商信息、产业链定位、微博舆情、百度大模型文本）的中小微企业信贷风险评估流程，包括多维度评分、企业相似度计算与风险等级分类。

## 核心流程

1. **多维度评分**（`从json文件得到企业多维度评分/score_1.py`）
   - 从企业 JSON 数据提取五大维度：全网评分、基本信息评分、稳定性评分、风险评分、创新评分。
   - 对不同字段做缺失值填充、归一化和分档打分。
2. **相似度计算**（`企业之间相似度计算/相似度计算.py`）
   - 对多维评分做 PCA 降维（10 维）+ 欧氏距离，再用倒数法转换为相似度。
   - 为每家公司找出最相似的 5 家。
3. **产业链定位**（`产业链相关/调用百度大模型获得企业产业链位置/公司爬取5.py`）
   - 调用百度文心大模型分析企业所属的 29 类产业链及上下游位置。
4. **风险等级分类**（`最终的风险评级/风险评级.py`）
   - 根据风险评分将企业划分为 `A / B / C / D / E` 五档。
5. **企业描述生成**（`使用百度大模型获取公司的描述/公司爬取.py`）
   - 调用百度大模型生成公司简介与信用代码等风险相关信息。
6. **微博舆情**（`微博搜索企业得到的内容/`）
   - 抓取企业在微博上的舆情数据，作为知识库的可选补充（暂未接入主流程）。

## 风险评级阈值

| 等级 | 风险评分区间 | 含义             |
| ---- | ------------ | ---------------- |
| A    | ≥ 90         | 极低风险         |
| B    | 80 – 89      | 低风险           |
| C    | 70 – 79      | 中等风险         |
| D    | 60 – 69      | 较高风险         |
| E    | < 60         | 高风险           |

## 快速开始

### 1. 安装依赖

```bash
pip install pandas numpy scikit-learn tqdm requests openpyxl jupyter
```

### 2. 配置百度大模型凭证

在使用 `公司爬取.py` / `公司爬取5.py` 之前，请先在 [百度智能云千帆大模型平台](https://cloud.baidu.com/) 申请 API Key 与 Secret Key，并在脚本顶部填入：

```python
API_KEY = "<你的 API_KEY>"
SECRET_KEY = "<你的 SECRET_KEY>"
```

### 3. 运行流程

```bash
# 1) 多维度评分（输入为企业 JSON 目录 ../data，输出到 ../output）
python 从json文件得到企业多维度评分/score_1.py

# 2) 相似度计算（输入 score2(1).csv，输出 company_similarity_results.csv）
python 企业之间相似度计算/相似度计算.py

# 3) 风险评级（输入 score1.csv，输出 classified_risk.csv）
python 最终的风险评级/风险评级.py

# 4) 百度大模型：企业描述与产业链定位
python 使用百度大模型获取公司的描述/公司爬取.py
python 产业链相关/调用百度大模型获得企业产业链位置/公司爬取5.py
```
